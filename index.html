How to Prepare and Upload SVG Files for GT7

01

Select Clean Artwork

Use a crisp PNG or high-res JPG with transparent or clean white backgrounds. Bold sponsor logos and racing emblems yield the cleanest vector contours.

02

Drop your file into our tool. The internal engine vectorizes the shape and executes progressive decimal reduction until the byte count is green-light certified (<15KB).

Frequently Asked Questions (Troubleshooting Decals)

Why does the GT7 decal uploader reject my file at 15.1KB?

Polyphony Digital's backend calculates the size in strictly binary kibibytes (KiB), capped at exactly 15,360 bytes. If your file is 15.1 KB (approx 15,462 bytes), the server will immediately throw an error dialog: "The uploaded file size exceeds 15KB." Our tool intentionally targets a safety threshold between 13.5KB and 14.8KB so you never trigger this barrier.

Why do certain colors or gradients vanish when uploaded to GT7?

Gran Turismo 7's in-game decal renderer only supports basic SVG paths and solid fills. It completely ignores complex gradients (<linearGradient>, <radialGradient>), embedded base64 bitmaps (<image>), and CSS styling classes. Our tool automatically converts outlines to pure path data (<path d="...">) compatible with the game engine.

Can I upload multi-color decals with this tool?

Yes. The tool groups primary visual shapes into clean monochrome layers. For complex multi-layered liveries (such as Red Bull Racing or Castrol graphics), veteran livery designers upload individual color passes as separate decals and stack them in the GT7 Livery Editor for pixel-perfect fidelity.

Does this work for custom helmet, suit, and car livery decals in GT7 Spec 4?

Yes! Every decal registered via the official Gran Turismo Community Decal Uploader is universally accessible across Car Liveries, Driver Helmets, and Racing Suits for all cars in Gran Turismo 7, including standard dealership models, Legend Cars, and Gr.3/Gr.4 championships.
